# EDA on Retail Sales Data

## Internship
Oasis Infobyte - Data Analytics

## Task
Level 1 - Task 1: Exploratory Data Analysis on Retail Sales Data

## Objective
To explore the retail sales dataset and identify useful patterns, trends, and relationships using Python.

## Analysis Performed
- Checked dataset structure and data types.
- Checked missing values and duplicate records.
- Analyzed product category distribution.
- Compared total sales by product category.
- Compared sales by gender.
- Analyzed monthly sales trends.
- Checked correlations between numerical variables.
- Compared product categories based on sales and quantity.

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
